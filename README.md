## Overview

A visual storytelling landing page practice project centered on nature imagery.

This project is part of a collection of front-end animation and interaction studies exploring modern scroll effects, transitions, and micro-interactions with GSAP and related libraries.

## Built With

- GSAP
- HTML5 & CSS3

## Getting Started

No build step required — this is a static HTML/CSS/JS project that loads its libraries from a CDN.

```bash
# Clone the repository
git clone https://github.com/asad-developer99/landing-nature.git
cd landing-nature
```

Then simply open `index.html` in your browser, or serve it locally for the best experience (recommended, since some browsers restrict local file access):

```bash
# using the VS Code "Live Server" extension, or:
npx serve .
```
